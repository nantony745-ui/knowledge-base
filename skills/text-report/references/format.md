# 输入与输出格式

输入为服务导出的 UTF-8 JSONL，不是文件路径列表：

```json
{"document_id":"文档UUID","original_name":"文档.md","content":"文档正文"}
```

每条记录三个字段都是字符串，`document_id` 非空。换行作为 JSON 字符串转义保存，文件名不参与统计。解析正文优先；没有解析路径时使用 TXT/MD 原文。不使用可能重叠的知识库片段拼接正文。

统计规则：

- 中文使用 `[\u4e00-\u9fff]+`：一个连续汉字片段计为一个词项，标点、空白分隔。没有专业 NLP、停用词、词性或语义排序。
- 英文使用 `[A-Za-z]+`：转为小写，数字、标点分隔，连字符及撇号分开统计。
- 段落为按空白行分隔的非空文本块。单个换行不拆段；Markdown 标题、列表与代码按普通正文处理。
- 关键词按频次降序、同频按字符串字典序。总体频次为逐文档频次之和，段落不跨文档合并。

`report.md` 包含规则说明、文档数、总段落数、总词项数、总体关键词频次和按选择顺序列出的逐文档统计；表格中的文件名转义竖线与换行。

`stats.csv` 固定表头：

```csv
document_id,original_name,metric,keyword,value
```

每份文档先写 `metric=paragraph_count`（keyword 为空），再写 `metric=keyword_count` 的各关键词及频次。CSV 使用标准库 csv 的引号和换行转义，UTF-8 编码。

空输入产出零统计报告和只有表头的 CSV。缺少 content、错误 JSON 或错误字段类型明确失败，完成输入校验前不写产物。相同输入重复运行产生相同文件内容。
