# 知识库上线检查清单

- 状态：现行
- 适用范围：产品演示

## 必须完成

对外发布前必须移除真实用户数据、个人联系方式、内部主机名和服务密钥。配置示例只保留占位值；数据库、向量索引和文档目录不得作为源码提交。

必须确认部署文档能在空环境完成依赖安装、数据库初始化和登录。至少验证一份文档的上传、索引、检索及来源跳转，并确认仓库可见性符合发布要求。

## 建议完成

建议提供简洁的功能截图、合成示例资料与常见问题说明。为关键流程保留自动化测试，明确外部模型服务的配置要求。

## 发布记录

记录版本、验证命令和实际结果。只记录通用操作信息，不记录真实凭据、个人路径或原始业务内容。
