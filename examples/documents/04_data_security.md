# 数据安全与访问规范

- 状态：现行
- 适用范围：产品演示

## 配置与凭据

服务密钥、管理员密码和签名密钥只能保存在本地环境配置或部署平台的秘密管理中。必须排除真实环境文件，配置模板使用通用域名和占位值。首次部署生成独立随机密码。

## 权限与来源

知识库查询和文档访问必须经过身份及归属校验。演示问答只选择演示知识库，引用需能够打开到相应文档片段。不得把未授权文档内容混入回答。

## 图片与日志

公开截图必须检查侧栏、会话标题、账号区和来源弹窗。建议统一截图尺寸和清晰度。日志及追踪内容也应经过脱敏，包含原始数据的导出文件不得提交到源码仓库。

## 发布前复核

必须检查待提交文件清单、图片内容和仓库可见性。建议用合成资料重现关键流程，避免直接复制业务数据。
