## 检索与原文阅读

智能推理采用原生 ReAct Agent，根据问题调用知识检索与文档阅读工具。涉及多份资料时，先查找相关证据，再读取原文片段；界面保留每轮工具名称、调用次数与返回数量，支持展开查看和历史会话恢复。

示例任务：结合《知识库上线检查清单》和《数据安全与访问规范》，整理对外发布前的检查项，区分必须项与建议项，并给出来源。

## 综合资料形成结论

将不同文档中的要求汇总成带引用的答案，支持表格与 Markdown 展示。每条引用关联本次推理中登记的证据，便于从结论返回对应资料。

![智能推理：带引用的检查项汇总](docs/images/reasoning-result.png)

## 打开来源核对原文

点击回答下方的来源卡片，查看对应文档名称、行号与原文片段，核对结论的依据。

![智能推理：查看引用原文](docs/images/reasoning-source.png)

## 运行智能推理

按[部署与开发文档](docs/deployment.md)启动服务，上传仓库内的[演示资料](examples/documents)，选择演示知识库与「智能推理」模式后输入问题。

```text
分别检索上线检查清单和数据安全规范，整理对外发布前的必须检查项与建议项，并引用来源。
```
